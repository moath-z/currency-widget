# Currency Widget

An Android home-screen widget that converts SAR, GBP and EUR. You type the amount on the widget's own keypad, so the app never opens.

**Install:** open the [latest release](../../releases/latest) on your phone, download `CurrencyWidget.apk` and open it.

**Add currencies:** edit `CURRENCIES` in `CurrencyWidget.java`. Pushing a change builds a new APK automatically.

Rates come from open.er-api.com and refresh every few hours, or when you tap ↻.
